# Seguridad y privacidad — fase de esqueleto

Este repositorio es una **plantilla académica**. No tiene autenticación, autorización por roles ni endpoints de negocio implementados. No está preparado para producción ni para almacenar datos personales o resultados de evaluaciones psicológicas.

Antes de desarrollar funcionalidades, definir roles, permisos, consentimiento, protección de datos, retención, cifrado, gestión de secretos y pruebas de seguridad. No subir credenciales, archivos `.env` ni información real de estudiantes.

La seguridad no debe darse por resuelta solo porque el repositorio de GitHub sea privado.
